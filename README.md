# FELEKTEN BİR QUIZ - GitHub Pages Paketi

Bu ZIP paketinin içinde oyunun HTML sürümü (`index.html`) yer almaktadır.

## Görseller Hakkında
- **Boyabat İnönü Öğretmenevi ve A.S.O. Müdürlüğü** sahnesi tamamen kod ile çizilmiştir ve hazırdır.
- **`OziCharacter2.png`** ve **`PixelCar.png`** görsellerini `index.html` ile aynı klasöre eklersen oyun bu görselleri otomatik olarak kullanacaktır. (Eklenmezse yedek çizimler görünür.)

## GitHub Pages'te Yayınlama
1. GitHub depona `index.html` dosyasını (ve varsa `OziCharacter2.png`, `PixelCar.png` dosyalarını) yükle.
2. **Settings -> Pages** menüsünden yayınlayacağın branch ve klasörü seçip kaydet.
